scores; the cells listed here carry the reported statistics only, because
per-video scores were never persisted for them. This file is generated by
`extract_predictions.py` and is the authoritative list — the build fails if
a cell declared here turns out to have scores after all, or if a cell
declared to have scores does not.

## What it would take to close these

Regenerating per-video scores for any cell above needs a forward pass of the
released checkpoint over that evaluation set's face crops. Crops are not
redistributable and are not currently on local disk; they are deterministically
regenerable from agreement-obtained source videos plus the per-video crop
coordinates in the Zenodo deposit (see the README). No re-training is involved.
